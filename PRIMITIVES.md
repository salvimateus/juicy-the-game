# Primitives

> Inventory of the atomic pieces of the Godot 4.7 project at `aventureiro-godot/`; paths are relative to the project root (`res://`).

Status is `confirmed` (implementation read) or `inferred`; `pending` marks a piece not yet committed to any branch.

## audio

- **`Sfx`**, `audio/sfx.gd`, confirmed, pending
  Single entry point for every procedural sound effect, playing a library that [[PRIMITIVES#SfxSynth]] renders once at load. Contract: autoload `Sfx`; `play(id: StringName, at: Vector2 = Vector2.INF, strength: float = 1.0, surface: StringName = &"")` plays a random variation, never the same one twice in a row for an id, surface and tier, through a pooled `AudioStreamPlayer2D` when `at` is given and a flat player otherwise; `strength` 0..1 picks the tier and attenuates by the id's `strength_db`, above 1 it adds up to +3 dB; a `surface` the id does not list falls back to its `default_surface`; `start_loop(id, at = Vector2.INF) -> int` returns a handle (0 when the id is not a loop) and starts at strength 1 from a random offset with a short fade-in, so a loop meant to start quiet needs `set_loop_strength` right after; `stop_loop(handle, fade = 0.08)` releases the handle at once and fades the player out before returning it for reuse, `fade <= 0` cuts; `set_loop_strength(handle, strength)` clamps the strength to 0..1 and sets a running loop's volume along the id's `strength_db` curve and its pitch between the id's `loop_pitch_low` and `loop_pitch_high`, times the loop's own pitch jitter, and does nothing for a stopped or unknown handle; `set_loop_position(handle, at)` moves a positional loop; `set_underwater(on, fade = 0.25)` ramps an underwater mix over `fade` (`<= 0` jumps) that closes the low-pass of the `SFX` bus from `UNDERWATER.open_hz` down to `cutoff_hz` and lowers the pitch of non-dry sounds toward `UNDERWATER.pitch`, live on running loops and at start on one-shots, so a one-shot already playing keeps its pitch; `is_underwater()` holds once the mix passes 0.5, so it flips halfway through a fade; `ids()`, `surfaces(id)` and `is_loop(id)` read [[PRIMITIVES#SfxTuning]]; `world: Node` is the parent of the positional players, so it must be set when the game world lives in a SubViewport, where `at` is a global position; signal `library_ready(generation_ms)` fires inside `_ready`, before the main scene exists. An id with `dry` plays on the `SFX_UI` bus and skips the underwater pitch drop, so `set_underwater` never reaches it; `dry` does not change pause handling. `play` on a loop or unknown id and `start_loop` on a one-shot or unknown id do nothing and warn once per id; for an id without a recipe see [[PRIMITIVES#SfxSynth]]. For one-shots, reaching an id's `max_voices` steals that id's oldest voice and a full pool steals the oldest voice of any id; loops take their own players outside the pools, with no voice cap, so `max_voices` on a loop id has no effect. Generation runs synchronously in `_ready` on the `WorkerThreadPool`, so the library is ready before the main scene. The autoload runs with `PROCESS_MODE_ALWAYS` and holds the flat players, so flat one-shots keep playing during pause, while the positional players are children of `world` when it is set and take its process mode; `pause_loops(on)` sets `stream_paused` on every running loop, dry or not, while one-shots keep playing, and [[PRIMITIVES#PauseController]] calls it while the pause menu is open. Buses come from code, since the project has no bus layout resource: the `SFX` bus and its compressor are created only when the bus is absent, so a bus layout that already defines `SFX` keeps its own effects, but a disabled low-pass is inserted first on `SFX` whenever it has none, and `set_underwater` drives the first low-pass of that bus; `SFX_UI` is created only when absent, sent to `Master` with no effects; a hard limiter is added to `Master` unless it already has one. `-- --sfx-dump <dir>` writes every variation as `.wav` plus `manifest.json` (default `res://captures/sfx`) and quits.
  Consumers: 6 (full search: `audio/sfx_board.gd`, `game/game.gd` and `game/pause_controller.gd` via `/root/Sfx`, [[PRIMITIVES#CaptureDriver]] via `/root/Sfx` reading the private `_loops`, [[PRIMITIVES#Feedback]], and `game/swim/swim_controller.gd` through `Feedback._node("Sfx")`; `game/swim/swim_controller.gd` calls `set_underwater` as the head goes under or out, and `game/game.gd` calls `set_underwater(false, 0.0)` on exit).
- **`SfxSynth`**, `audio/sfx_synth.gd`, confirmed, pending
  DSP toolkit plus one recipe per sound id, rendering the raw buffers that [[PRIMITIVES#Sfx]] turns into its library. Contract: no `class_name`, consumed through `preload`; static `prepare_tables()` builds the shared white, pink and brown noise tables from `BASE_SEED`, is a no-op while they exist and must run before any `render`; static `release_tables()` drops them, which [[PRIMITIVES#Sfx]] does on `_exit_tree`; static `job_seed(key, tier, variation)` is the deterministic seed of one variation; each instance owns its `rng` and serves one job, and the tables are read-only after preparation, so jobs run on worker threads with one instance each; `render(id, params, weight, surface) -> PackedFloat32Array` calls `_r_<id>(params, weight, surface)`, with `params` the id's `synth` dict and `weight` 0..1 the tier position; `finish(buf)` DC-blocks, trims the silent tail, fades both ends and normalizes to `TARGET_PEAK`; `to_stream(buf, loop) -> AudioStreamWAV` encodes mono 16-bit at `SAMPLE_RATE`, with `LOOP_FORWARD` over the whole buffer when `loop`. An id of `SOUNDS` without a matching `_r_<id>` still loads and is listed by `Sfx.ids()`: `render` returns an empty buffer and pushes a warning for every variation, tier and surface rendered at load, so the id plays silence and nothing warns at play time; recipes draw randomness only from the instance `rng` (`rr`, `noise`), which keeps every variation deterministic per seed and safe across threads; [[PRIMITIVES#Sfx]] skips `finish` for loop ids, so a loop recipe renders its loop plus a crossfade tail and returns `finish_loop(buf, xf)` itself.
  Consumers: 1 (`audio/sfx.gd`).
- **`SfxTuning`**, `audio/sfx_tuning.gd`, confirmed, pending
  The only place for the playback knobs and the main synthesis knobs of every sound id, plus the library-wide constants. Contract: no `class_name`, consumed through `preload`; `SOUNDS` maps each `StringName` id to its overrides of `DEFAULTS`, which holds every playback key with its default, and its `synth` dict holds the parameters its recipe in [[PRIMITIVES#SfxSynth]] reads; the `dry`, `loop_pitch_low` and `loop_pitch_high` keys act as described in [[PRIMITIVES#Sfx]]; `config(id)` returns `DEFAULTS` merged with the entry, `{}` for an unknown id; the constants set sample rate, base seed, finishing, the `SFX` bus volume and compressor, the `SFX_UI` bus name (`DRY_BUS_NAME`), the underwater low-pass and pitch (`UNDERWATER`), the `Master` limiter, pool sizes, the loop fade-in and 2D attenuation. A new sound is a `SOUNDS` entry plus its recipe, and `Sfx.ids()` reads `SOUNDS`, so there is no other registry; an entry without a recipe still loads, see [[PRIMITIVES#SfxSynth]].
  Consumers: 2 (full search: `audio/sfx.gd`, `audio/sfx_synth.gd`).

## haptics

- **`Haptics`**, `feedback/haptics.gd`, confirmed, pending
  Single entry point for joypad rumble, mixing every pulse and loop into one weak/strong motor pair, plus the phone motor of the touch controls. Contract: autoload `Haptics`; profiles live in `PROFILES` of `feedback/haptics_tuning.gd`, format documented in its header, keyed by a subset of the [[PRIMITIVES#Sfx]] ids; `play(id, strength = 1.0)` fires a one-shot pulse, ignored for an unknown or loop profile and below the profile's `gate`; `start_loop(id, strength = 1.0) -> int` returns a handle (0 when the profile is not a loop) and `stop_loop(handle)` fades it out over `LOOP_FADE`, taking no fade argument; `set_loop_strength(handle, strength)` changes a running loop's strength, clamped to the tuning's `MAX_STRENGTH` like `start_loop`; `has_profile(id) -> bool` holds for any id in `PROFILES`, loop or not, so callers use it to fall back to another id; `pause_all(on)` silences the motors, drops the pending pulses and freezes the mix clock, so loops resume where they were on `pause_all(false)`; `enabled` set to false sends zero at once; `intensity` scales the mix, clamped to 0..1.5; `device` is the target joypad (-1 none, making everything a no-op) and follows the last joypad button or axis input and connection changes; a connection change that moves `device` forces the mix to be sent again to the new pad (after the pause, when paused), while a switch by input does not, and neither path stops the old pad, which the motors drive with duration 0, so it keeps its last rumble (inferred from the engine's `start_joy_vibration`). Each motor takes the max of the live layers and loops, never their sum, quantized to `QUANT_STEP` and sent only when it changes; the motors stop on focus loss and close; the autoload runs with `PROCESS_MODE_ALWAYS`; handles are independent from `Sfx` handles, so a caller pairing both keeps two. `handheld(amplitude, duration)` is a separate phone-motor path through `Input.vibrate_handheld`, a no-op without the `mobile` feature or while `enabled` is false, scaled by `intensity` and independent of `device` and `pause_all`, so it vibrates with no pad connected; a pulse landing inside one still playing is dropped unless clearly stronger, and [[PRIMITIVES#Feedback]] has no wrapper for it. `-- --haptics-sim` prints the mix timeline of a scripted scenario and quits.
  Consumers: 8 (full search: `audio/sfx_board.gd` and `game/pause_controller.gd` via `/root/Haptics`, the latter calling `pause_all` while the pause menu is open; [[PRIMITIVES#CaptureDriver]] via `/root/Haptics` reading the private `_paused`, whose `joy` op also reaches the connection handler; [[PRIMITIVES#Feedback]]; through `Feedback.haptics()`, `game/debug_hud.gd`, which sets `enabled` and `intensity`, and `game/combat/bow.gd` and `game/interactables/interactable.gd`, which call `has_profile` to pick a fallback id; [[PRIMITIVES#TouchControls]] calls `handheld` through the global name `Haptics`).

## rig animation

- **`RigMath`**, `rig/rig_math.gd`, confirmed, pending

## physics

- Collision layers: `project.godot` names none. Layer 1 holds the world and the player (engine default, nothing sets it), layer 5 is debris and layer 7 is combat hitboxes; layer 7 is written in five separate places, the `hitbox_layer` export of [[PRIMITIVES#BreakableWall]], the `HITBOX_LAYER` constant of [[PRIMITIVES#Hurtbox]] (which the balloons and cup hitboxes reuse), the `area_mask` export of [[PRIMITIVES#Arrow]], the query mask of [[PRIMITIVES#Hitbox]] and the ray mask of `game/combat/guns.gd`, so changing it means changing all five. The player keeps the default mask 1 and runs its step, push and stand probes with that mask, so a body on any other layer never blocks or supports it.
- Gravity: `project.godot` sets no 2D gravity, so a RigidBody2D falls at the engine default 980 while the player integrates its own `gravity` export (2600, times `fall_gravity_multiplier` 1.35 while falling) in `game/player.gd`; a rigid body that must fall like the player sets `gravity_scale` to its game gravity over `physics/2d/default_gravity`; [[PRIMITIVES#MotoBike]] uses neither and integrates the lighter `GRAVITY` of [[PRIMITIVES#MotoTuning]].
- Body metas: bodies the player stands on or grabs carry `surface` (StringName the player reads from its first floor collider and passes to its footstep, land, jump and roll sounds, also read by [[PRIMITIVES#FlyingKick]] on a wall and by [[PRIMITIVES#Guns]] for the fog burst; a floor without it keeps the last value), `wall_top` and `wall_bottom` (world y range of the face, read by the wall grab, defaulting to -INF and INF; `wall_top` INF makes a body never grabbable, as on [[PRIMITIVES#MotoTrack]]), and a grabbable wall also joins group `climbable_wall` unless the player's `wall_grab_any` is on; [[PRIMITIVES#Level]] sets them on its ground, stone and tunnel bodies, and [[PRIMITIVES#SteelPlate]] and [[PRIMITIVES#MotoTrack]] on their own.

Contract: `class_name WaterBody`, `extends Node2D`, joins group `water` (`GROUP`) in `_enter_tree`; `domain` is a Rect2 local to the node, split into `cell`-wide simulation columns (`cell` a multiple of the art pixel) with momentum per edge and exact volume bookkeeping, plus one ripple spring and one shader texel per art-pixel column; every public method takes and returns global coordinates: `is_point_in_water(global_pos) -> bool`, `get_surface_y(global_x, near_y) -> float` (INF when the column is dry or `near_y` is underground there, the water top inside a flooded passage), `get_submerged_ratio(rect: Rect2) -> float`, `get_flow_at(global_pos) -> Vector2` (zero outside the water; near a flowing orifice it pulls toward the inlet, plus a weaker horizontal drawdown drift toward it from far away), `apply_disturbance(global_pos, velocity)` (waves, plus a small splash when fast at the surface), `emit_bubbles(global_pos, count, velocity = Vector2.ZERO)`, `emit_splash(global_pos, strength)` (strength clamped to 0.05..1.5, plays `splash` itself), `fill_level(global_x0, global_x1, global_level_y)` (fills the columns whose bed lies below the level, queued until the first rasterize), `store_rest_state()`, `restore_rest_state(duration := 0.6)` (clears parcels and drops and blends the depths back; without a prior `store_rest_state` it drains to dry), `get_total_volume()` (columns plus parcels plus pending spills), `get_floor_y(global_x)`, `get_depth_at(global_x)`, `get_active_orifice_near(global_pos, radius) -> Dictionary` (the flowing orifice whose inlet, the centre of its upstream face, is nearest within `radius`, with global `inlet`, `outlet`, `top`, `bottom`, `x_in` and `x_out`, plus `dir`, +1 when it flows right, and `speed`, the jet speed; empty when none flows), `is_ready()`, and signal `rasterized`, fired once after the first rasterize, one physics frame after `_ready`. - **`Fog`**, `game/fog/fog.gd`, confirmed, pending
  Purely visual swamp fog over the level: a GPU fluid step in a SubViewport that follows the camera, drawn as pixel art by two world-space layers; nothing in gameplay reads it back. Contract: autoload `Fog`, `PROCESS_MODE_ALWAYS` with its simulation time frozen while the tree is paused; `enabled` is off by default (no terrain build, no simulation, nothing drawn), `game/game.gd` turns it on in `_ready` unless `--fog-off` is given, `--fog` turns it on in any scene, and as an autoload it keeps its value across a scene change, so [[PRIMITIVES#MotoLevel]] turns it off for its stage; `density_scale` (clamped to 0 and above), `opacity_scale` (multiplies the layers' alpha), `quality` (`Quality` `LOW`, `MEDIUM`, `HIGH`, picking the simulation cell from `SIM_CELL`, 18, 12 and 6 units), `wind`; impulses `push`, `burst`, `line`, `sweep`, `swirl` and `add_density` in global coordinates, at most `MAX_IMPULSES` per frame and dropped outside the simulation window or while it is not accepting (disabled, terrain not ready or headless); `set_body(id, global_pos, velocity, radius)` and `clear_body(id)` for up to `MAX_BODIES` bodies, each expiring `BODY_TTL` after its last update; `rebuild_terrain()`, `invalidate_solids(rect)`, `reset()`, `stats()`. The simulation window is the visible rect of the root viewport's `Camera2D` plus `MARGIN`, re-centred every frame, so a camera inside a SubViewport is not followed and without a camera nothing is drawn; headless runs build no nodes. The two layers are `Sprite2D` nodes with `z_as_relative` off at z -3 (`BACK_Z`) and 30 (`FRONT_Z`), drawn by `game/fog/fog_layer.gdshader` as a quantized density ramp with a 4x4 Bayer dither (offset on the front layer), banks and wisps gated by `detail`; their visual knobs come from [[PRIMITIVES#FogTuning]], set by name once when each layer is made (`detail` again on a quality change), the simulation uniforms every frame and the terrain uniforms when the terrain build ends, while `knee_lo`, `knee_hi`, `ground_sink_px`, `stone_sink_px` and `front_share` stay shader-only defaults; `ART` is hardcoded to 6 instead of read from [[PRIMITIVES#GameScale]] and pushed to the shader's `art` uniform; water per the water volume contract of `## water`.
  Consumers: >=5 (`game/game.gd`, `game/debug_hud.gd` and [[PRIMITIVES#MotoLevel]] through `/root/Fog`; `game/fog/fog_test.gd` by name; `game/fog_hooks.gd`, the guarded bridge that is a no-op while the autoload is missing or disabled, preloaded by `game/game.gd`, `game/player.gd`, [[PRIMITIVES#Fists]], [[PRIMITIVES#FlyingKick]], `game/combat/kunai.gd`, [[PRIMITIVES#Guns]] and `game/swim/swim_controller.gd`).
- **`FogTuning`**, `game/fog/fog_tuning.gd`, confirmed, pending
  The only place for the visual knobs of the fog layers. Contract: `extends RefCounted`, no `class_name`, consumed through `preload`; `COMMON` (both layers), `BACK` and `FRONT` (one layer each) map uniform names of `game/fog/fog_layer.gdshader` to values, and `DETAIL_BY_QUALITY` is indexed by `Fog.Quality`; [[PRIMITIVES#Fog]] sets every key by name when it makes each layer, so a value applies to layers made after it, and the shader's own defaults for these keys are overwritten duplicates, so retuning happens here, not in the shader.
  Consumers: 1 (full search: [[PRIMITIVES#Fog]]).
